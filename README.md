# Hi, I'm Dekirai 👋

I'm a developer from Germany who enjoys building software around the games and communities I care about. My projects range from game-specific tools and modding utilities to Discord integrations that make it easier to share what I'm playing.

## What I'm working on

- **Game tools and modding:** utilities for browsing, editing, and managing game resources.
- **Discord Rich Presence:** ways to share game activity with friends, including games that don't provide native Discord support.
- **Gaming projects:** PC tools, ports, and community projects inspired by the games I enjoy.

## Featured projects

### Discord Rich Presence

- [**SwitchPresence**](https://dekirai.crygod.de/switchpresence) — Bring your **Nintendo Switch** activity to Discord with Rich Presence. It includes **playtime tracking** and works **without downloading or installing an app**. Visit the site to get started.
- [**MultiPresence**](https://github.com/Dekirai/MultiPresence) — Discord Rich Presence for games that don't support it natively. It detects supported games and lets you customize what appears on your profile.

### S4 League tools

A set of utilities for exploring and working with S4 League's resources and interface files:

- [**S4LResourceTool**](https://github.com/Dekirai/S4LResourceTool) — Browse S4 League archives, preview supported resources, and manage files with convenient drag-and-drop and batch operations.
- [**S4LResReplacer**](https://github.com/Dekirai/S4LResReplacer) — Apply custom resource files to the game and restore the original resources afterward.
- [**S4LXUIEditor**](https://github.com/Dekirai/S4LXUIEditor) — A visual editor for S4 League `.xui` interface files.
